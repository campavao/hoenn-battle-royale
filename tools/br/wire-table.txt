# The mailbox's message table (POK-331 #21): every BR_MSG id, and for a message that
# spans slots the most bytes it packs to (BR_CAP), which is what the ROM's assembler for
# it holds. This is the only place either is written:
#
#     python3 tools/br/wire-ids.py
#
# makes include/br/br_wire_ids.h and web/src/net/wire-ids.ts from it, and
# web/src/net/wire-ids.test.ts fails when either has drifted. Each message's bytes are in
# include/br/br_wire.h, under its name; docs/WIRE.md has what each is for.
#
# Add at the end. No id may set 0x80, the continuation bit (BR_MSG_CONT), or reach
# BR_MSG_COUNT, the ROM's dispatch table. The name, id and cap of every row hash to
# BR_WIRE_HASH, and that hash is the last row of tools/br/wire-protocols.txt, under
# BR_PROTOCOL: a message added, retired or renumbered, or a cap moved, is a new protocol.
# wire-ids.py writes nothing until the new hash is a new row there, and the ROM does not
# build until BR_PROTOCOL is that row's (wire-protocols.txt says what else holds it). The
# notes after a `#` are not hashed.
#
# name       id   cap
NONE          0
ECHO          1         # page -> ROM, echoed back: the bridge's heartbeat
PLACE         2
STEP          3
FACE          4
CHALLENGE     5
BT            6   261   # seat, seq u16, len u16, a 256-byte block
PARTY         7   667   # seat, count, 6 * 100, then money u32, stacks, 20 * (id, n)
FAINT         8
OUT           9
PICKUP       10
SPILL        11   128   # 4 + 6 * 9, bag flag, key/x/y, 8 * 3 items, money, 1 + 7 name
RING         12
CLOCK        13
START        14   266   # 10 + 32 spawn rows * 8
TICKER       15
RESULT       16
BUSY         17
BSTART       18  1230   # 28 + 2 * (count + 6 * 100): what a fighter's ROM sends
TURN         19   128   # what a fighter's ROM sends in one frame
FOLLOW       20
PEEK         21
SHOT         22
TRAINER      23   619   # seat, 1 + 7 name, count, 6 * 100, items, 4 * u16
PICK         24
LAND         25
SPENT        26
DUEL         27  1222   # 4 + 12 * 100, then two bags of (count, 4 * u16)
DRESULT      28
FLED         29
GIVE         30
NPCOUT       31
