# hud-vram: the HUD shares BG0's tiles with the start menu and the message box, and
# every window that comes up over it gets them clean (POK-329). The corner is 0x139..
# 0x153 (the start menu's head), the box 0x154..0x1C3 (the menu's tail and the message
# box's head), the ticker 0x1C8..0x1FF (the message box's tail): BG2's tilemap is at
# screen block 25 (BrField_InitRingBgs), and BG0 keeps no tile from 0x240 on.
# BrHud_Yield hands a HUD window's tiles over on the frame another window comes up over
# it, and BrHud_Tick draws it again the frame after that window goes.
#
# Littleroot: 7 LEFT and the clock, a kill line on the ticker, and the ring's box coming
# up beside them; then, one after another over all three, the START menu (five items,
# the box still up), Brendan's house sign, the spectator's peek box, and the map-name
# popup after a warp, with the box running out under it. Every frame through each is
# watched (VRAM's tilemap and tiles, every live BG0 window, gBrHud's first 16 bytes, and
# BG1..3's control registers, their tilemaps in VRAM and the field's buffers for them)
# and tools/br/hud-vram.py checks each cell naming a shared tile shows its owner's pixels,
# that none names a tile at or above 0x240, that the corner and the ticker are back the
# frame after whatever was over them goes, and that BG1..3 show the field's own tilemaps.
# checked-by: tools/br/hud-vram.py
wait 30
pokebytes gBrMailbox+0x2018 81 00 00 09 05 00 08 00 BD BB C7 FF
wait 400
# the match is on (MAP is a START row while it is), and the page writes 7 left, 2:05
poke u8 gBrMatch 2
poke u8 gBrHud+0x00 7
poke u16 gBrHud+0x02 125
# a kill line from seat 1 (TICKER, as hud.txt): "MAY GOT BRENDAN"
pokebytes gBrMailbox+0x1018 0F 15 12 00 00 01 00 0F C7 BB D3 00 C1 C9 CE 00 BC CC BF C8 BE BB C8
poke u16 gBrMailbox+0x0C 1
wait 4
# RING phase 1 naming LITTLEROOT (as ring-place.txt): the corner names it and the box
# comes up to say the fog closes in on it -- 0x154..0x1C3, beside the corner's tiles and
# the ticker's, and the one HUD window that comes and goes on its own

watch gOverworldTilemapBuffer_Bg3 4
watch *gOverworldTilemapBuffer_Bg1 4096
watch *gOverworldTilemapBuffer_Bg2 4096
watch *gOverworldTilemapBuffer_Bg3 4096
wait 2
poke u16 gBrMailbox+0x0C 2
wait 10
unwatch
say box-up
# all three up: shown = CORNER|TICKER|BOX, each first cell its own base tile. BG0's
# tilemap is 0x0600F800, 32 cells a row, palette 15: (20,1) the corner, (1,11) the box,
# (1,17) the ticker

expect u16 0x0600FAC2 0xF154
expect u16 0x0600FC42 0xF1C8
