# spectate-turn: the challenger publishes a link battle (BR_MSG_BSTART: seed + both
# parties) and streams its actions (BR_MSG_TURN) to spectators (POK-233). Loopback
# battle (myId 0 = challenger); once it is up, `started` is set; pick FIGHT + a move to
# run a turn, and the spectate counter climbs -- action bytes went out on the wire.
drain gBrMailbox
wait 30
pokebytes gBrMailbox+0x2018 81 00 00 09 05 00 08 00 BD BB C7 FF
wait 400
# the eyeline only fires in a started match (gBrMatch.phase = BR_PHASE_PLAY)
poke u8 gBrMatch 2
poke u8 gBrNetlink+8 1
# CHALLENGE: challenger 00, opponent 01
pokebytes gBrMailbox+0x1018 05 07 04 00 00 00 01 00 00
poke u16 gBrMailbox+0x0C 1
wait 900
expect u16 gBrSpectate 0
# the battle is set up: the challenger has published BR_MSG_BSTART (seed + parties)
expect u8 gBrSpectate+4 1
# at the action menu: FIGHT, then the first move, to run one turn
tap A
wait 40
tap A
wait 200
expectge u16 gBrSpectate 1
expectge u16 gBrSpectate+2 1
say spectate turn ok
