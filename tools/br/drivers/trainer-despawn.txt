# trainer-despawn: a trainer we have beaten stays gone (POK-232). The despawn list is
# swept once per map load, so a sprite the match has retired does not walk back in when
# the player does. Littleroot's own NPC 1 -- the twin at (16,10) -- stands in for a beaten
# route trainer here; the sweep does not care how a local id got onto the list. Boot two
# tiles south of her, because Emerald only keeps object events near the camera and a sprite
# out of range is not there to remove.
wait 30
pokebytes gBrMailbox+0x2018 81 00 00 09 10 00 0C 00 BD BB C7 FF
# gBrDespawned[0] = { mapGroup 0, mapNum 9, localId 1 }
pokebytes gBrDespawned 00 09 01
wait 400
# the sweep took one sprite off this map
expectge u8 gBrLoot+0xA3 1
shot gone
say trainer despawn ok
