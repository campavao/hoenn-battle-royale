# field-view: the picture the ROM declares (POK-329). gBrFieldView sits in ROM and the
# page reads it out of the patched image before it boots the core: the band to draw past
# the LCD (left, top, right, bottom) and the sprite window it reads each OAM y against
# (spriteTop, spriteBottom), every field a u16. A ROM without it gets the page's legacy
# band, 0/40/16/56 with the same window: one 256-row ring. This ROM's ring is 512 rows,
# and the view is all of it but the spare row a step needs: 184 above the LCD and 152
# below, 496 rows (include/br/br_field.h; 104 and 232 before POK-378).
wait 30
expect u16 gBrFieldView+0 0
expect u16 gBrFieldView+2 184
expect u16 gBrFieldView+4 16
expect u16 gBrFieldView+6 152
expect u16 gBrFieldView+8 40
expect u16 gBrFieldView+10 56
# ...and the wide ring's (THE WIDE RING), for a screen it covers more of: 512x256 BGs,
# the LCD's 240 columns and 128 each side, 31 of the ring's 32, and pret's 16 rows less
# the spare one, 40 each side. The sprite window is the same.
expect u16 gBrFieldViewWide+0 128
expect u16 gBrFieldViewWide+2 40
expect u16 gBrFieldViewWide+4 128
expect u16 gBrFieldViewWide+6 40
expect u16 gBrFieldViewWide+8 40
expect u16 gBrFieldViewWide+10 56
say ok
