# object-slots: ghosts and loot take object slots only where the engine keeps objects, the
# nearest first, and never the last few the map's own people need (POK-330 #48).
#
# OBJECT_EVENTS_COUNT is 16. Ghosts and balls used to spawn wherever their cell was, in
# seat order, and again every frame after each camera step culled them, so twelve ghosts
# and a spill at the far end of a route held every slot as the route's own people scrolled
# into view -- and those were simply not there. Now: only inside the box
# RemoveObjectEventIfOutsideView keeps, never the last BR_NPC_HEADROOM (3) free slots,
# and the nearest to the middle of the view first.
#
