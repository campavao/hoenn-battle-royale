# ring-place: the HUD corner names where the ring is closing, all ring phase long
# (POK-325). The play-test missed the ninety-frame "THE FOG CLOSES IN ON" box and had
# nothing else to go on. The corner is 9x3 now (cols 20..28, frame 19..29): "N LEFT" and
# the clock on its first line, the place -- or FOG EVERYWHERE on the last phase -- right
# on its second, the eye left of it or taking turns with it. Shots are for the eye.

pokebytes gBrMailbox+0x2018 81 00 00 09 05 00 08 00 BD BB C7 FF
wait 400
# the page writes 12 left and 12:34: the widest first line there is

poke u16 gBrMailbox+0x0C 1
wait 30
# the name is kept, EOS-ended, at gBrRing+14
expect u8 gBrRing+4 0x1C
expect u8 gBrRing+5 0
expect u8 gBrRing+14 0xC6
expect u8 gBrRing+15 0xC3
expect u8 gBrRing+16 0xCE
expect u8 gBrRing+17 0xCE
expect u8 gBrRing+18 0xC6

expect u8 gBrRing+20 0xCC
expect u8 gBrRing+21 0xC9
expect u8 gBrRing+22 0xC9
expect u8 gBrRing+23 0xCE

# first ring's rung is the one the match had (POK-324), so shown = CORNER|BOX. BG0's
# tilemap is 0x0600F800, 32 cells a row, palette 15. The corner's first cell (20,1) is
# 0x139 and its last (28,3) 0x153; the box's first (1,11) is 0x154, right after it -- the
# HUD shares the start menu's and the message box's tiles (POK-329, br_hud.h). Its frame

expect u8 gBrHud+0x09 5
expect u8 gBrHud+0x0A 0
expect u16 0x0600F868 0xF139
expect u16 0x0600F8F8 0xF153
expect u16 0x0600FAC2 0xF154
expectne u16 0x0600F826 0
shot corner-place
# the box goes after its ninety frames; the corner keeps the name
wait 90
