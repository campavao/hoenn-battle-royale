# zone-pool: the Safari's catch pool is dealt from the match seed (POK-255), not read
# off Emerald's own Zone table. Twelve first stages from the whole dex bar the legendaries --
# and the same twelve on every ROM in the room, because the deal is a pure
# function of the seed the START carried rather than anything sent.
#
# The encounter itself cannot be driven here (POK-269: the harness cannot run a wild
# battle past its intro), so this checks the deal, which is the part that is ours. The
# expected twelve were worked out by running the same generator offline -- mulberry32
# to the bit, the one clock.ts uses, so the page can mirror this without a second
# implementation.
wait 30
# boot mode 2 = the Safari Zone
pokebytes gBrMailbox+0x2018 02 00 00 00 00 00 00 00 BD BB C7 FF
wait 400
expect u8 gBrMatch 1
# nothing is dealt before there is a seed to deal from
expect u32 gBrZone 0
# START, seed 0x12345678
pokebytes gBrMailbox+0x1018 0E 15 12 00 00 78 56 34 12 01 78 00 78 00 00 00 00 19 0A 00 28 00 00
poke u16 gBrMailbox+0x0C 1
wait 30
expect u32 gBrMatch+8 0x12345678
# BrMatch_BeginSafari deals it, so by now it is there and it is this seed's
expect u32 gBrZone 0x12345678
# Twelve first stages from the whole dex bar the legendaries (2026-10-20), none twice, no
# type theme: MAKUHITA, NATU, CHANSEY, TOTODILE, PICHU, PARAS, CHINCHOU, VULPIX, SLOWPOKE,
# HOOTHOOT, GOLDEEN, EEVEE -- Kanto and Johto as well as Hoenn, and nothing that evolves
# from something else, so nothing out of the opening is a level-5 SALAMENCE. (Species ids
# are pokeemerald's internal ones: Hoenn's run from 277.)
expect u16 gBrZone+4 335
expect u16 gBrZone+6 177
expect u16 gBrZone+8 113
expect u16 gBrZone+10 158
expect u16 gBrZone+12 172
expect u16 gBrZone+14 46
expect u16 gBrZone+16 170
expect u16 gBrZone+18 37
expect u16 gBrZone+20 79
expect u16 gBrZone+22 163
expect u16 gBrZone+24 118
expect u16 gBrZone+26 133
# ...and the deal no longer says "A <TYPE> MATCH!" on the ticker
expect u8 gBrHud+0x0A 0
wait 60
shot pool
say zone pool ok
