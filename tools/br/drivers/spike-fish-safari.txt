# spike-fish-safari: a rod in the Safari opening hooks a WATER Pokemon (Cam, the launch
# video: "go to any body of water, including in the Safari, to try and catch one").
# BR_WILD_ASKED_FISH with BR_WILD_FISH_SAFARI used to roll the opening's any-first-stage,
# so a Safari cast hooked SHUPPET or CHARMANDER (rom d4658e4, four casts). Five casts on
# ROUTE 102's pond (0:17, which has a fishing table) as the Safari's, each one's enemy
# battler dumped (gBattleMons[1], 0x24 bytes: species +0, types +0x21) and run from;
# then the same five as a plain SUPER ROD, which keep their own table's water mon.
