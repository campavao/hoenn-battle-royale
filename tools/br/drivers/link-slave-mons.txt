# link-slave-mons: a link battle's slave runs no battle engine, so nothing filled its
# gBattleMons -- the move menu said "ELECTR x1" for THUNDER on an AMPHAROS, from the types
# the last battle left there (Cam's 2026-10-27 play-test). BrBattle_FillSlaveMons fills
# what the menus read from the parties. netlink-loop.txt's loopback battle (we are the
# master), then IS_MASTER taken off for a moment so this ROM is a slave as far as that
# goes.
drain gBrMailbox
wait 30
pokebytes gBrMailbox+0x2018 81 00 00 09 05 00 08 00 BD BB C7 FF
wait 400
# the eyeline only fires in a started match (gBrMatch.phase = BR_PHASE_PLAY)
poke u8 gBrMatch 2
poke u8 gBrNetlink+8 1
# CHALLENGE: type 5, framed len 7 = hdr(04 00 00) + challenger 00, opponent 01, nonce 00 00
pokebytes gBrMailbox+0x1018 05 07 04 00 00 00 01 00 00
poke u16 gBrMailbox+0x0C 1
wait 6
expect u8 gBrNetlink 1
expect u8 gBrNetlink+1 0
expect u8 gBrNetlink+2 1
expect u8 gWirelessCommType 5
wait 600
# five blocks went out: header, party x3, rng seed
expectge u16 gBrNetlink+12 5
expectge u16 gBrMailbox+0x08 6
# gWirelessCommType 5 is "wireless" to every upstream truthy test, so each VBlank of this
# fight runs RfuVSync and the battle draws the wireless indicator, both of which read
# gRfuLinkStatus. That is safe only because the boot's InitRFU pointed it at the API
# buffer with parentChild MODE_NEUTRAL (0xFF), where rfu_syncVBlank does nothing
# (POK-330 #31, include/br/br_netlink.h).
expectne u32 gRfuLinkStatus 0
expect u8 *gRfuLinkStatus+0 0xFF
shot battle
wait 300
# both TREECKOs out: GRASS, GRASS (gBattleMons[1].types at +0x58+0x21)
expect u8 gBattleMons+0x79 0x0C
# what a slave's gBattleMons looks like: whatever the last battle left -- here a GHOST
# called nothing -- and the engine's IS_MASTER (bit 2 of gBattleTypeFlags) gone
pokebytes gBattleMons+0x79 07 07
pokebytes gBattleMons+0x88 FF
pokebytes gBattleMons+0x0C 00 00
copy gBrMailbox+0x1E00 gBattleTypeFlags 1
expectbits u8 gBattleTypeFlags 0x04 0x04
poke u8 gBattleTypeFlags 0x2A
wait 2
# filled back from the parties: the foe's types and name, our moves
expect u8 gBattleMons+0x79 0x0C
expect u8 gBattleMons+0x7A 0x0C
expectne u8 gBattleMons+0x88 0xFF
expectne u16 gBattleMons+0x0C 0
copy gBattleTypeFlags gBrMailbox+0x1E00 1
say link slave mons ok
